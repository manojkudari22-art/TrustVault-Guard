# TrustVault — Project Plan and Daily Progress

## Project Overview

TrustVault is a secure document-sharing platform developed for the Snovasys Fresher Hiring Challenge 2026.

The application focuses on secure document access, role-based permissions, and an audit trail of document activities.

## Project Plan

### Day 1 — 2026-11-01
- Understand the challenge requirements.
- Define the project scope and architecture.
- Set up the project repository and folder structure.
- Prepare initial documentation and security threat analysis.

### Day 2 — 2026-11-02
- Implement user registration, login, and logout.
- Implement password hashing.
- Add Administrator, Document Owner, and Viewer roles.
- Protect dashboards using role-based access control.
- Write authentication and authorization tests.

### Day 3 — 2026-11-03
- Implement secure document upload.
- Add document listing and management.
- Validate uploaded files.
- Restrict document access to authorized users.

### Day 4 — 2026-11-04
- Implement document-level read and edit permissions.
- Allow document owners to grant and revoke access.
- Add audit logging for document activities.
- Test unauthorized document access.

### Day 5 — 2026-11-05
- Implement document search and filtering.
- Add administrator activity and permission-change views.
- Complete remaining core functionality.
- Run security and functional tests.

### Day 6 — 2026-11-06
- Deploy the application.
- Perform end-to-end testing.
- Fix bugs and improve security.
- Update README and deployment documentation.

### Day 7 — 2026-11-07
- Prepare the final project demo.
- Review project documentation.
- Verify GitHub repository and deployed application.
- Complete challenge submission.
