# TrustVault - Secure Document Sharing

## Problem Statement
Build a secure document sharing platform where unauthorized users cannot read confidential files and every important action is recorded in an audit trail.

## Main Goals
- Secure user authentication
- Role-based access control
- Private document storage
- Document permissions and revocation
- Audit logs
- Security testing

## User Roles
- Admin
- Document Owner
- Viewer

## Security Principles
- Default deny
- Least privilege
- Immediate permission revocation
- Secure file storage
- Tamper-evident audit trail
