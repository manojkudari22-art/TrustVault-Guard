# TrustVault Requirements

## Functional Requirements
1. Users can register and log in.
2. Admin can manage users.
3. Document owners can upload documents.
4. Owners can grant and revoke document access.
5. Viewers can access only authorized documents.
6. The system records document activity.
7. Users can search documents by metadata.
8. Unauthorized actions are blocked.

## Security Requirements
1. Passwords must be securely hashed.
2. All document access must be authorized.
3. Uploaded files must be stored privately.
4. Access permissions must be checked on every request.
5. Permission revocation must take effect immediately.
6. Audit logs must be tamper-evident.
7. Security tests must verify unauthorized access is blocked.
