# TrustVault-Secure

A secure document-sharing platform built for the Snovasys Fresher Hiring Challenge 2026.

## Problem
Share confidential documents securely and maintain a tamper-evident audit trail.

## Technology
- Python
- Flask
- SQLite
- Flask-SQLAlchemy
- Flask-Login
- Pytest

## Main Features
- User authentication
- Role-based access control
- Secure document storage
- Document permission management
- Audit logging
- Security testing
